Themis

因果验证器

服务已经起来了，但这台机器上还没有构建好的前端，所以这里没有产品页面可以给你。

构建一次就好（需要 Node 与 pnpm）：

cd themis/web/frontend
pnpm install
pnpm build

然后刷新本页。以后每次改了前端源码都要重跑 pnpm build，否则浏览器拿到的还是上一次构建的包。

这一页只是在告诉你还差一步，它不显示任何结果——内核算出来的东西只由构建好的产品来讲， 那一份才受「每个词表都要说人话」「每个字段都要交代去处」这两条约束管着。 在构建好之前，/api/run 一类接口照常可用，/docs 是它们的自述页。
