# Themis 统一现场体验 —— 使用说明

一个网站覆盖从普通用户到专业用户的全光谱。后端全程跑**真实的 themis**（不是录像/假数据）。

## 启动

双击 **`启动demo.bat`** → 自动开浏览器到 `http://127.0.0.1:7860`。关黑窗口即停。

（双击没反应：命令行进本文件夹跑 `python app.py`。需要 Python 装了 `fastapi uvicorn pandas`，Ask 模式还要 `anthropic`，本机 3.13 都有。）

## 四个标签页

### ① 问问题（普通用户）— 走本机 Max 代理，免配置
中文随便打一个因果问题（“多吃蔬菜能降血压吗”）→ 系统翻成因果图、跑内核、再用中文如实回答。
**这是你 `themis/web` 的 Ask 能力，复用了同一套 `llm_bridge`。**
- LLM 调用**默认走本机 Max 代理 `http://127.0.0.1:7777`**（`api_key="x"` 占位，代理负责真鉴权）。
  → **不用填 key、不撞 429、不烧按量额度**。前提：那个 proxy 在本机 24/7 跑着。
- 代理地址可用环境变量 `THEMIS_DEMO_PROXY` 覆盖；输入框里若填了真 key 也会被尊重。
- 若 demo 跑在别的机器，proxy 必须能从那台机器访问到（本机就是 `127.0.0.1:7777`）。
- 实在没代理也没 key，就用 ②，离线照样演内核行为。

### ② 选场景（零配置、永不翻车）
6 个预置因果问题，点一个 → 运行 → 看内核真实判定：状态徽章 / 识别公式 / 数据缺口诊断 / JSON。
第一个“靶向药+混杂”对应 **PPT 第 6 页**。

### ③ 编辑 kernel_ast（技术向）
直接改 JSON 跑真实内核。适合导师当场问“去掉这条边会怎样”，改给他看。

### ④ 专业：数据 → 真数字 ★新增
用“靶向药 → 肿瘤反应（疾病严重程度是混杂）”：
- 点「**用内置示例数据跑**」立即出结果，或上传你自己的 CSV（三列：`targeted_drug, tumor_response, disease_severity`）。
- 结果**并排对比**：
  - ❌ 未调整的粗相关（普通人直接对比会得到的、被混杂带偏的数）
  - ✅ Themis 后门调整估计 + 95% 置信区间 + E-value 敏感性
- **核心一幕**：两个数字明显不同 → 直观证明“为什么要做因果调整”。数字来自数据、带 CI、可 `themis.verify` 复核，不是 LLM 编的。

## 这条光谱讲给导师

| 用户 | 用哪个标签页 | 价值 |
|---|---|---|
| 普通人，只有一句话 | ① 问问题 | 诚实：缺数据就说缺，不编 |
| 想看内核怎么判 | ② 选场景 / ③ 编辑 | 识别公式 + 缺口诊断 |
| 专业人，有数据 | ④ 专业 | 真点估计 + 置信区间 + 敏感性 |

—— 同一个内核，左端给诚实诊断，右端给可复核的真数字。SciGraph 在左/中段都能给 DAG 做机制接地。
