# Themis — Design Context

## Design Context

### Users
One product, three audiences:
1. **Decision-makers / non-technical askers** — type a causal question ("久坐会少活几年?"), need an *honest* answer, not a confident fabricated number. The "Ask" face.
2. **Analysts / the owner** — build a causal DAG by hand, upload data, run identification + numeric estimation. The "Build / Estimate" face.
3. **Visitors being shown Themis** — must grasp in five seconds: *this is the tool that refuses to fake certainty.* The showcase.

Context of use: at a desk, thinking carefully about one causal claim, usually already skeptical of confident AI answers. Reading a verdict + a list of what data is still missing — text-heavy, read slowly.

### Brand Personality
Three words: **clinical, honest, exacting.** A scientific instrument / verifier, not a hype SaaS chatbot. Themis earns trust precisely by refusing to fake a number — the absence of an answer is itself a precise reading. Emotional goal: *relief + respect* — "finally, something that tells me what it actually knows and exactly what's missing."

### Aesthetic Direction
- **Instrument, not dashboard.** Measurement device / scientific-paper register. Calm, exact, document-like. No hype, no SaaS gradients.
- **Theme: light.** Careful reading of a verdict and caveats at a desk; a paper/document register reads as more trustworthy and is easier for long captions. (Not the reflexive dark "AI" look.)
- **The hero moment is the verdict readout.** `answer_tier` (point / interval / none) presented like an instrument's status reading — the most prominent thing on the screen. "none" must feel like a *correct precise measurement*, never an error or a shrug.
- **Anti-references:** confident-chatbot UIs; purple→blue gradient SaaS; neon-on-dark "AI" aesthetics; hero-metric templates; the side-stripe-bordered alert card.

### Design Principles
1. **Honesty is the aesthetic.** Make "no number / interval / point" read as a precise instrument reading. `answer_tier` is the hero field, never hidden.
2. **Instrument, not chatbot.** Restraint, precision, document register. One memorable signature element (the verdict readout) carries the identity.
3. **Severity legible at a glance — without the banned tells.** Gap report ranks blocking > important > informational using typographic weight, leading numerals/labels, and tinted surfaces — never a colored left-border stripe.
4. **Chinese-first, terms explained inline.** Audience includes non-technical readers; surface the plain-language translation, keep the rigorous term as a quiet annotation.
5. **Calm motion, one orchestrated reveal.** The verdict lands with a single composed entrance, not scattered micro-animations.

### Type & Color (decided)
- **Display / wordmark / verdict labels:** Spectral + Noto Serif SC (scholarly serif).
- **Body / UI:** Hanken Grotesk + Noto Sans SC (precise grotesque).
- **Formulas / bounds expressions / data only:** Spline Sans Mono (legitimate notation alignment, not decorative "dev vibe").
- **Color:** light, paper-tinted neutrals nudged toward an ink hue; OKLCH throughout; reduce chroma near white. answer_tier states get three restrained, distinct hues (point = grounded green-teal, interval = ochre, none = muted clay) used as compact status marks, not big fills.
